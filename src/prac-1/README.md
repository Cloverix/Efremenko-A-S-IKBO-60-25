### *window.py - эмулятор командной строки на языке python.*

Эмулятор реализован в виде графического интерфейса с использованием библиотеки tkinter.

Синтаксис вызова эмулятора: python3 window.py \[--vfs путь к директории] \[--script путь к скрипту] \[--config путь к конфигу]

**Описание параметров:**
\--vfs - путь к стартовой директории виртуальной файловой системы
\--script - путь к текстовому файлу, содержащему последовательность команд, которая должна быть выполнена до начала работы
\--config - путь к .xml файлу, содержащему аргументы vfs и/или script для эмулятора. Аргументы, переданные в командной строке, преобладают над аргументами из конфигурационного файла.
Допустимая структура .xml файла конфига:
<{имя корневого тэга}>
	\<vfs>...\</vfs>
	\<script>...\</script>
</{имя корневого тэга}>
